# Reporting a security problem

Please use [GitHub private vulnerability reporting](https://github.com/tcballard/omarchy-perch/security/advisories/new)
if it is enabled for this repository. If that route is unavailable, open a
minimal issue asking for a private reporting channel without publishing the
vulnerability details, credentials or private data.

Include the Perch commit, affected integration, reproduction steps and impact
in the private report. Automated checks and preview testing are limited
evidence, not a security audit. Perch is native plugin code running in the
Omarchy shell process; it is not an isolation boundary for untrusted plugins.
